# EV Charging Station Demand & Location Intelligence

**Portfolio Project | Business Analytics**

## Business Scenario
An EV charging operator wants to improve station utilization and decide where additional charging capacity should be considered.

This portfolio case study uses a **synthetic dataset designed around real EV-charging business questions**. Public datasets such as CHARGED provide hourly charging volume, duration, prices, weather and geospatial attributes across multiple cities, showing that these are realistic dimensions for EV charging analysis. [Scientific Data, 2025]

## Business Questions
1. Which stations have the highest utilization?
2. What are the peak charging hours?
3. Which stations generate the most revenue?
4. Which stations are under-utilized?
5. When should additional capacity be considered?
6. Which station profiles should management prioritize?

## KPIs
- Charging Sessions
- Energy Delivered (kWh)
- Utilization Rate
- Revenue
- Average Session Duration
- Revenue per Session
- Peak-Hour Demand

## Tools
Python • Pandas • NumPy • Matplotlib • Scikit-learn • SQL/Power BI ready

## Project Structure
- `ev_charging_analysis.py` — complete analysis
- `ev_charging_data.csv` — synthetic project dataset
- `station_summary.csv` — station KPI output
- `output/` — charts

## Portfolio Disclaimer
The dataset in this project is synthetic. It is designed to demonstrate analytics skills and should not be presented as actual company data or actual business results.

## Suggested Portfolio Description
"Built an EV Charging Station Demand & Location Intelligence case study using Python to evaluate station utilization, charging demand, revenue performance and peak-hour behavior, translating operational data into expansion and capacity-planning recommendations."

## Real-world context
The analysis structure is informed by public EV charging datasets and planning tools. CHARGED contains hourly charging duration, charging volume, electricity price, service price, weather and geospatial information across six cities. The IEA's EV Charging and Grid Integration Tool also emphasizes charging-demand profiles and peak-load planning.
